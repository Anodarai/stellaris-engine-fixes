# Benchmark saves

Add these single-player, non-Ironman saves to this directory, keeping their names and case.

| File | Workload | Warm-up | Measured |
|---|---|---:|---:|
| earlyGame.sav | Early campaign | 3 days | 90 days |
| midGame.sav | Developed empires | 3 days | 90 days |
| lateGame.sav | Heavily developed galaxy | 3 days | 90 days |
| bigBattle.sav | Large battle already underway | 1 day | 10 days |

A fixture should have a stable camera position and an uninterrupted measurement window. A save
using mods needs a matching benchmark profile. The runner stages each source save under the
benchmark profile's save directory before launching Stellaris.
